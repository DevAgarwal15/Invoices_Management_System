Guidance

Using ENV_BILLING

A quick reference for the billing workflow.

1

Create an invoice

Open New Invoice, enter the customer, amount, and payment status, then save. The invoice number is generated automatically.

2

Find and view invoices

Use the invoice ledger search for an invoice number or customer name. Select View to open the protected invoice document.

3

Understand payment status

Paid invoices are complete. Pending invoices still require payment follow-up. Use the status filter to narrow the ledger.

FAQ

Can I edit an invoice?
Editing is not available in the current workflow. Create a new record if the original contains an error.

Who can see my invoices?
Only the authenticated owner of an invoice can view it in the application.
